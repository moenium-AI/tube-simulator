 1. ソフトの概要
----------------------------------------------------------------

Tube Simulatorは、真空管アンプの動的な振る舞いを再現するWindows向け
オーディオ・プラグインです。foobar2000 v2.x 64bit用DSP版と、64bit
VST3ホスト用プラグインを、同じ操作パネルと共通のRealtime Coreで提供します。

主な機能は次のとおりです。

  - Standard / Dynamic PSU / OPT Magnetic / Full Referenceの4 Character
  - Input Drive / Output / Auto Gain / Level Match
  - COMPAREによる処理音と基準信号の比較
  - Auto / 1x / 2x / 4xの内部オーバーサンプリング
  - 既定のLinear / High Qualityで302-frame処理レイテンシ
  - Resampler profile別のPDC（Linear 302 / 263 / 218、Minimum 28 frames）
  - 44.1 / 48 / 88.2 / 96 / 176.4 / 192 kHz
  - モノラル / ステレオ
  - Factory Preset、入出力メーター、Diagnostics、About

310A、300B、274Bは、技術的・歴史的な型式参照を示す名称です。これらの
名称は説明目的で使用しており、特定の企業やブランドとの提携、承認、推奨を
示すものではありません。

 3. 動作環境
----------------------------------------------------------------

  OS        : Windows 64bit
  ホスト    : foobar2000 v2.x（64bit）または64bit VST3ホスト
  CPU       : x86-64（Intel / AMD）
  出力      : ホストが開けるオーディオデバイス

追加ソフト: 不要

32bitのfoobar2000および32bit VSTホストには対応していません。
高いサンプルレートやOversampling倍率ではCPU負荷が増加します。
Resampler profileを変更した場合、Linear High / Standard / LightのPDCは
それぞれ302 / 263 / 218 frames、Minimumは28 framesです。

 4. インストール方法
----------------------------------------------------------------

foobar2000 DSP版：

  1. foobar2000を終了します。
  2. 同梱のfoo_dsp_tube_simulator.fb2k-componentをダブルクリックします。
     （またはFile > Preferences > ComponentsのInstall...を使用します）
  3. Applyを選択してインストールを完了します。

インストールしただけでは再生チェーンに入りません。File > Preferences >
Playback > DSP Managerを開き、「Tube Simulator」をActive DSPsへ移し、
Configure selectedで設定画面を開いてください。

VST3版：

同梱のVST3\TubeSimulator.vst3フォルダーを、使用するVST3ホストが検索する
VST3プラグインフォルダーへコピーし、ホストで再スキャンしてください。
配布アーカイブにはWindows x86_64用バイナリが含まれます。


----------------------------------------------------------------
 5. 使い方
----------------------------------------------------------------

設定画面には、入力、出力、Character、Oversampling、Resampler profile、
Auto Gain、Level Match、COMPARE、Factory Preset、Diagnostics、Aboutの
各項目があります。各コントロールの現在値とホスト状態は画面で確認できます。

最初は再生音量を下げ、StandardまたはFactory Presetから少しずつ調整する
ことをおすすめします。Auto GainとLevel Matchは音量を整える機能であり、
安全リミッターではありません。

----------------------------------------------------------------
 6. アンインストール方法
----------------------------------------------------------------

foobar2000 DSP版：

  1. File > Preferences > Playback > DSP Managerを開き、
     「Tube Simulator」をActive DSPsから外します。
  2. File > Preferences > Componentsを開き、「Tube Simulator DSP」を
     選択して削除します。
  3. Applyを選択し、foobar2000を再起動します。

VST3版：

ホストのVST3プラグインフォルダーからTubeSimulator.vst3フォルダーを
削除し、ホストを再スキャンしてください。

設定やホスト側のキャッシュが残る場合は、ホストが提供する設定管理機能を
使用してください。


----------------------------------------------------------------
 7. 動作に関するご注意
----------------------------------------------------------------

【再生音量について】

Input Drive、Output、Auto Gain、Level Match、COMPAREの組み合わせにより、
ピークレベルや聴感上の音量が変化します。再生音量を下げた状態から設定を
始め、最終出力レベル、聴覚、機器の保護は利用者自身の責任で管理してください。

【OversamplingとResampler profile】

高い倍率や高品質profileほどCPU負荷が増えます。VST3ではprofileの変更が
次回のhost prepareまたはrestart後にPDCへ反映されます。実際の処理レートは
DiagnosticsのHOST RATEで確認できます。

【設定の保存先】

設定はfoobar2000のプロファイルまたはVST3ホストのproject/state管理に
保存されます。配布アーカイブには利用者の設定は含まれません。

【無音時の動作】

真空管モデルの処理とホストのtail契約により、完全なデジタル無音でも
数学的な完全無音とは限りません。
