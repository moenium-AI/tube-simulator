 1. Обзор
----------------------------------------------------------------

Tube Simulator — аудиоплагин для Windows, моделирующий динамическое поведение
лампового усилителя. Он включает 64-битный DSP-компонент для foobar2000 v2.x и
64-битный плагин VST3. В обоих вариантах используются одна панель управления
и общий Realtime Core.

Основные возможности:

  - Четыре режима Character: Standard, Dynamic PSU, OPT Magnetic,
    Full Reference
  - Input Drive, Output, Auto Gain и Level Match
  - COMPARE, независимый от Level Match
  - Линейно-фазовая Oversampling: Auto / 1x / 2x / 4x
  - Задержка обработки 302 frames с профилем по умолчанию Linear / High Quality
  - PDC для профилей: 302 / 263 / 218 frames для Linear High / Standard / Light,
    и 28 frames для Minimum
  - 44,1 / 48 / 88,2 / 96 / 176,4 / 192 kHz
  - Работа в моно и стерео
  - Factory Presets, входные и выходные индикаторы, Diagnostics и About

Названия 310A, 300B и 274B используются только как технические и исторические
обозначения типов. Их использование не означает аффилированности, одобрения,
спонсорства или поддержки со стороны какой-либо конкретной компании или бренда.

 3. Требования
----------------------------------------------------------------

  ОС       : Windows 64 bit
  Хост     : foobar2000 v2.x (64 bit) или 64-битный VST3-хост
  CPU      : x86-64 (Intel / AMD)
  Вывод    : Любое аудиоустройство, которое может открыть хост

Дополнительное ПО: не требуется

32-битные foobar2000 и VST-хосты не поддерживаются. Более высокие частоты
дискретизации и коэффициенты Oversampling увеличивают нагрузку на CPU. При
изменении профиля Resampler PDC составляет 302 / 263 / 218 frames для Linear
High / Standard / Light и 28 frames для Minimum.

 4. Установка
----------------------------------------------------------------

DSP для foobar2000:

  1. Закройте foobar2000.
  2. Дважды щёлкните по прилагаемому файлу
     foo_dsp_tube_simulator.fb2k-component.
     (Или откройте File > Preferences > Components и выберите Install...)
  3. Выберите Apply для завершения установки.

Одна установка компонента не добавляет его в цепочку воспроизведения. Откройте
File > Preferences > Playback > DSP Manager, переместите "Tube Simulator" в
Active DSPs и используйте Configure selected для открытия окна настроек.

VST3:

Скопируйте прилагаемую папку VST3\\TubeSimulator.vst3 в папку VST3-плагинов,
которую сканирует ваш хост, затем повторно просканируйте плагины. Архив содержит
двоичный файл для Windows x86_64.


----------------------------------------------------------------
 5. Начало работы
----------------------------------------------------------------

Окно настроек содержит Input, Output, Character, Oversampling, Resampler profile,
Auto Gain, Level Match, COMPARE, Factory Preset, Diagnostics и About.

Начните с низкой громкости воспроизведения и постепенно регулируйте параметры,
начав с Standard или Factory Preset. Auto Gain и Level Match регулируют уровень;
это не защитные лимитеры.


----------------------------------------------------------------
 6. Удаление
----------------------------------------------------------------

DSP для foobar2000:

  1. Откройте File > Preferences > Playback > DSP Manager и уберите
     "Tube Simulator" из Active DSPs.
  2. Откройте File > Preferences > Components, выберите "Tube Simulator DSP"
     и удалите его.
  3. Выберите Apply и перезапустите foobar2000.

VST3:

Удалите папку TubeSimulator.vst3 из папки VST3-плагинов, используемой хостом,
затем повторно просканируйте плагины.

Если настройки или кэш хоста сохранились, используйте собственные средства
управления настройками хоста.

 7. Примечания по использованию
----------------------------------------------------------------

[Уровень воспроизведения]

Input Drive, Output, Auto Gain, Level Match и COMPARE могут изменять пиковый
уровень или воспринимаемую громкость. Начните с низкой громкости и самостоятельно
контролируйте итоговый уровень, безопасность слуха и оборудования.

[Oversampling и профили Resampler]

Более высокие коэффициенты и профили высокого качества используют больше CPU.
В VST3 изменение профиля отражается в PDC после следующей подготовки хоста или
перезапуска. Фактическую частоту обработки, предоставленную хостом, можно
проверить в Diagnostics в разделе HOST RATE.

[Где хранятся настройки]

Настройки сохраняются в профиле foobar2000 или в управлении проектом/состоянием
VST3-хоста. Пользовательские настройки не входят в архив выпуска.

[Поведение при тишине]

Из-за обработки модели ламп и соглашения о хвосте хоста цифровая тишина не всегда
является математически точным нулём.
